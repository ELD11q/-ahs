LUNAR LANDING SITE NAVIGATOR

🌕 مستكشف مواقع الهبوط القمري

نظام مفتوح المصدر يختار أفضل مواقع الهبوط على القطب الجنوبي للقمر، ببيانات ناسا الرسمية ونوافذ الإطلاق الحقيقية لعام 2027.

Open-source system that ranks landing sites at the lunar south pole using official NASA data and real 2027 launch windows.

شغّله بنفسك

git clone https://github.com/ELD11q/-ahs.git
cd -ahs/lunar-landing-navigator
python -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python -m lunar_nav --nasa -o output     # downloads ~1.2 GB of NASA data on first run

أو من حسابك على GitHub بدون تثبيت: سوّ Fork، بعدها افتح Actions وفعّل الـ workflows، واختر Lunar Landing Navigator واضغط Run workflow.
